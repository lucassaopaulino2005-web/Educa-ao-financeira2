# Dinheiro em Dia — Educação financeira e economia digital

Site estático, responsivo e em português. Não precisa de servidor, banco de dados ou instalação.

## Arquivos
- `index.html`: conteúdo e estrutura.
- `style.css`: identidade visual e layout responsivo.
- `script.js`: menu mobile e calculadora de orçamento.

## Como publicar no GitHub Pages
1. Crie um repositório no GitHub (por exemplo, `educacao-financeira`).
2. Envie os três arquivos (`index.html`, `style.css` e `script.js`) para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação. O GitHub mostrará o endereço do site na seção Pages.

O projeto usa Google Fonts via internet; se estiver offline, fontes locais padrão serão utilizadas.
